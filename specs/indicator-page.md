# indicator-page 模块规格

负责：注入网页的「操作指示器」。Agent 操作页面期间，在页面上显示三样东西：一圈提示边缘、一个让用户随时叫停的 Stop 按钮、以及点击前短暂出现的光标。三者与页面自身的 DOM / 样式 / 脚本相互隔离，页面脚本既看不到也改不了它们。

## 1. 视觉一律自定（硬约束）

页面上画出来的一切视觉，包括颜色、光标图形、边框粗细与样式、动画与过渡、各元素尺寸与位置、按钮外观、按钮上的文字，**全部由实现者自定**，本规格不给任何取值，测试也不断言。只冻结第 4–7 节的可观察行为。

仅有的视觉相关约束，都是行为性的：

| 约束 | 原因 |
|---|---|
| 边框、光标不拦截任何鼠标事件（页面按钮照常被点到） | 指示器不能妨碍 Agent 和用户操作页面 |
| 显示出来的东西相对页面可见，页面上有高层级全屏遮罩时 Stop 仍能被真点到 | Stop 是紧急叫停，不能被盖住 |
| Stop 按钮在可访问树里是**恰好一个**有非空可访问名的按钮；文案自定 | 辅助技术和测试都靠它定位 |
| `show` 后画面相对未显示时有可见变化；`hide` 后画面与未显示时完全一致；光标出现时只改动其坐标附近的画面 | 像素级「有没有」的判定依据；具体画成什么样自定 |

## 2. 脚本形态（硬约束）

- **经典脚本，不是 ES 模块**：文件里不得出现 `import` / `export`。扩展用 `chrome.scripting.executeScript({ files: [...] })` 注入，带 `export` 会语法错误；测试也用普通脚本方式注入。
- 运行在扩展的隔离世界（isolated world）里，用 `chrome.runtime.sendMessage` 与扩展通信。
- 执行后在 `window.__jevIndicator` 上挂一个对象，**恰好 5 个**函数：`show`、`hide`、`moveCursor`、`state`、`stopCenter`。不挂其他键。这个名字和 5 个函数名是对外接口（后台用 `window.__jevIndicator[op](...args)` 调用）。
- **同一页面重复执行无副作用**：已存在 `window.__jevIndicator` 时什么都不做（不替换对象，已显示的指示器保持原样）。
- 导入时的副作用：只有挂上述全局对象。不改 DOM、不往 `window` / `document` 上挂事件监听、不起定时器；初始状态下页面上什么都没有，页面外观与未注入时一致。
- 页面刷新 / 跳转后状态全部清空，由扩展重新注入。

## 3. 依赖

无。不 import 任何同目录模块。只用网页标准 DOM API 和一个扩展 API：

| 用到的 API | 用途 |
|---|---|
| `chrome.runtime.sendMessage(msg)`，返回 Promise（没有接收方时 Promise 会拒绝） | 点击 Stop 时通知扩展 |

### 调用方依赖的契约

| 调用方 | 依赖什么 |
|---|---|
| 扩展后台 | 点击 Stop 时收到的消息形如 `{ type: 'STOP' }`（只有这一个键，值是这个字符串，大小写固定） |
| 扩展后台 / 测试 | `window.__jevIndicator.state()` 与 `stopCenter()` 的返回形状（见第 4 节） |

## 4. 冻结的签名

全部同步；除 `state` / `stopCenter` 外返回值恒为 `true`。函数自己不抛异常。

| 函数 | 参数 | 返回 |
|---|---|---|
| `show` | 无 | `true` |
| `hide` | 无 | `true` |
| `moveCursor` | `x: number, y: number`（当前 frame 视口的 CSS 像素） | `true` |
| `state` | 无 | `{ border: boolean, stop: boolean, cursor: boolean }`，恰好这三个键 |
| `stopCenter` | 无 | Stop 按钮中心的视口坐标 `[x, y]`（两个有限数字）；Stop 没有被创建（从未 show 或已 hide）时返回 `null` |

`state` 字段含义：

| 字段 | 为 true 的条件 |
|---|---|
| `border` | 边框已显示且在文档中 |
| `stop` | Stop 当前可见且可点（已显示，且未处于 6.3 的让位状态） |
| `cursor` | 光标当前处于「可见停留」状态（见 6.1） |

`stopCenter` 只看 Stop 是否存在：让位期间 `state().stop` 为 false，但 `stopCenter` 仍返回其原位置。Stop 显示时，该坐标落在视口之内。

## 5. show / hide

| 输入情形 | 可观察结果 |
|---|---|
| 初次 `show` | 边框与 Stop 都出现，`state` 为 `{ border: true, stop: true, cursor: false }`，`stopCenter` 非 null |
| 已显示时再次 `show` | 不重复创建：可访问树里仍恰好一个按钮；若之前 Stop 被光标让位收起，这次让它恢复显示 |
| `hide` | 同步移除，不留过渡 / 淡出动画：返回时边框、Stop、光标已全部消失，`state` 三项全 false，`stopCenter` 为 `null`，画面恢复成未显示时的样子；停留中的光标计时一并作废，之后不再有任何延迟动作 |
| 没 `show` 过就 `hide`，或连续 `hide` | 无副作用，返回 `true`，不报错 |
| `hide` 之后再 `show` | 与初次 `show` 等价，指示器重新出现 |
| `show` 后页面脚本把 `body` 清空 | 再次 `show`（或 `moveCursor`）后指示器重新出现在文档里，Stop 可正常使用 |
| 文档没有 `body`（只剩根元素） | `show` / `moveCursor` / `hide` 照常返回 `true`，不抛错；指示器此时是否出现不约束 |

### 与页面的隔离

| 情形 | 结果 |
|---|---|
| 页面脚本在显示期间扫文档里的元素（封闭 shadow 只防页面脚本；测试用调试协议穿透它，实现不需要也不应去防调试协议） | 看不到任何新增的按钮或其他指示器元素；没有任何元素暴露可读的 shadow root（用封闭的 shadow root 承载全部内容） |

## 6. moveCursor

### 6.1 光标出现与淡出

| 输入情形 | 可观察结果 |
|---|---|
| 没 `show` 就 `moveCursor(x, y)` | 光标单独出现：`state` 为 `{ border: false, stop: false, cursor: true }`；可访问树里没有按钮 |
| 已 `show` 时 `moveCursor` | `state` 为 `{ border: true, stop: true, cursor: true }`（坐标不在 Stop 上时） |
| 光标出现后 | 先停留可见一小段，再自行淡出。**停留时长项目自定**；可依赖的保证：调用后 300 ms 内 `state().cursor` 仍为 true；调用后 2500 ms 内会变回 false |
| 停留期间再次 `moveCursor` | 光标挪到新位置并重新计时 |
| 光标停留期间 `hide` | 光标立即消失；原计时作废，之后到点也不报错、状态保持全 false |

停留时长的由来：项目自定——足够让用户在点击前看到操作位置，又不长期遮挡页面内容。

### 6.2 位置与不挡点击

- 光标画在给定坐标附近，只改动该处附近的画面，不动远处。具体图形、大小、锚点偏移自定。
- 光标不拦截鼠标事件：光标落在页面按钮上后立刻真点，页面按钮收到点击。

### 6.3 坐标落在 Stop 上

| 输入情形 | 可观察结果 |
|---|---|
| `moveCursor` 的坐标落在 Stop 按钮的矩形内（含边界） | Stop 立即收起（不可见、不可点）：`state().stop` 为 false；此刻真点该坐标不发 `STOP` 消息，点击落到 Stop 下方的页面元素 |
| 光标淡出之后 | Stop **不会**自动恢复，保持收起，直到下一次 `show` |
| 之后再 `show` | Stop 恢复显示，可再次真点并发 `STOP` |
| 坐标不在 Stop 矩形内 | Stop 保持不变 |

由来：Agent 要点的位置恰好被 Stop 盖住时，必须让位，否则 Agent 的点击会误触叫停。

### 6.4 非常规坐标

`NaN`、`Infinity`、字符串、缺参数等一律不抛错，返回 `true`，不影响已显示的边框 / Stop；这种坐标下光标画在哪里自定。

## 7. Stop 按钮

| 输入情形 | 可观察结果 |
|---|---|
| 用户真点击（`isTrusted` 为 true） | 向扩展发送一条 `{ type: 'STOP' }`；每次真点击各一条；点击不改变显示状态（边框、Stop 仍在） |
| 页面脚本伪造的点击（`isTrusted` 为 false）：对页面可达的节点派发、调用 `click()` 等 | 无效，不发消息 |
| 任何 `isTrusted` 为 false 的点击，不论落在哪个节点（含按钮本身，含用调试协议直接对按钮派发） | 都不发 Stop 消息（只认真实用户输入） |
| 页面上有全屏、高层级的遮罩 | 真点 Stop 仍有效 |
| `sendMessage` 返回的 Promise 拒绝（没有接收方） | 静默忽略：不产生页面未捕获异常，不产生未处理的 Promise 拒绝 |
| `hide` 之后真点原 Stop 位置 | 不发消息 |
| 被光标让位收起期间真点该处 | 不发消息（见 6.3） |

## 8. 测试不断言的输出（自定）

颜色、边框粗细、光标图形与大小、Stop 的位置 / 尺寸 / 文案 / 字体、动画与过渡时长与曲线、光标停留时长的精确值（仅 6.1 的两个界限被冻结）、封闭 shadow root 内部结构、层级数值（唯一约束：测试里的页面遮罩层级在 100000 量级，指示器须在其之上，具体数值自定）。测试只用「画面有没有变化」「可访问树里有几个按钮、名字是否非空」「真 / 假点击是否发出消息」「状态函数的返回」判定。

## 9. 常量来由

本模块不规定任何数值常量，全部视觉与计时取值「项目自定」；唯一冻结的数值边界是 6.1 的 300 ms / 2500 ms，由来：项目自定的可观察下限与上限，给实现留出自由度，同时让测试与后台能稳定判断「出现了」与「会消失」。
